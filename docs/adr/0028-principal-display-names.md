# 0028: プリンシパルの表示名を GUI のラベルとして保持する

- ステータス: 採択
- 日付: 2026-10-01

## 背景

[ADR 0016](0016-oidc-bearer-auth-and-gui.md) は，監査ログと `requestedBy` に
書くアクターを `principalClaim` の値（Entra ID では `oid`）とし，表示名は
アクターではないと決めた．これは正しいが，GUI の操作記録や run の一覧では
操作者が GUID で並び，誰の操作かを人が読み取れない．Entra ID のアクセス
トークンは `profile` スコープがあれば `name`（表示名）を持っており，推奨の
スコープにはすでに `profile` が含まれている．

## 決定

- **表示名はラベルであり，識別子ではない．** アクター・`requestedBy`・
  `retiredBy` などに記録するのはこれまでどおり `principalClaim` の値である．
  監査イベントの行は何も変わらない．
- **トークンの表示名をプリンシパルごとに 1 つ保持する．** 設定
  `server.auth.oidc.displayNameClaim`（既定 `name`，`-` で無効）のクレームを
  読み，認証されたリクエストのたびに (authority, name) ごとの最新値を
  `principal_names` に書く（値が変わったときだけ．プロセス内でキャッシュする）．
  値が無い・長すぎる・印字可能でないときは表示名なしとして扱い，リクエストは
  拒否しない．書き込みに失敗しても警告をログに出すだけである．監査はしない．
- **GUI が識別子を表示名に置き換える．** `GET /principals` の一覧を引き，
  操作記録・run・ACME アカウントの世代・退役・利用側の台帳の更新者を表示名で
  表示する．識別子と authority はツールチップと run の詳細に残し，絞り込みは
  識別子でも効く．表示名のないプリンシパル（`localhost-dev`，`scheduler`，
  この変更以降まだ API を呼んでいない人）は識別子のまま表示する．

## 結果

- 表示名は **現在の** 名前であり，操作した時点の名前ではない．改名すれば過去の
  操作もその人の新しい名前で表示される．操作した時点の記録が要るときは識別子で
  たどる（Entra ID の監査ログや `oid` からの照会）．
- 表示名は一意でない．同名の 2 人は GUI 上では同じに見えるので，区別が要る
  ときはツールチップか run の詳細の識別子を見る．
- Conductor はプロバイダにユーザーを問い合わせない．保持するのはプロバイダが
  トークンで主張した値だけであり，ADR 0016 の「プロバイダが主張したものが
  そのままログの内容になる」は変わらない．
- 表示名は viewer にも見える．viewer はすでに監査ログ全体を読めるので，新たに
  開示されるのは識別子に対応する名前である．
